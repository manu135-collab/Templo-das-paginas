# 3.3. Diagramas de Atividades

## Atividade: realizar empréstimo (Figura 6)

Fluxo: início → identificar leitor → informar exemplar → verificar cadastro ativo e ausência de pendências (RN05). Se inválido, exibir o motivo da recusa e encerrar; se válido, verificar limite de empréstimos (RN01) e tipo/disponibilidade do exemplar (RN07); se aprovado, registrar empréstimo, calcular a devolução (RN02) e emitir comprovante.

## Atividade: login (Figura 7)

Fluxo: início → inserir e-mail e senha → validar dados → credenciais válidas? Se não, exibir mensagem de erro e retornar à inserção; se sim, acessar o sistema → exibir a tela inicial → fim.
