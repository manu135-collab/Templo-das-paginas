# 2.1. Requisitos Funcionais

| ID | Nome | Descrição | Prioridade |
|---|---|---|---|
| RF01 | Realizar login | O sistema deverá permitir que usuários cadastrados acessem a aplicação mediante e-mail e senha. | Essencial |
| RF02 | Cadastrar leitor | O sistema deverá permitir o cadastro de novos leitores, com o registro de dados pessoais e de contato. | Essencial |
| RF03 | Encerrar sessão | O sistema deverá permitir que o usuário encerre sua sessão de forma segura. | Essencial |
| RF04 | Gerenciar acervo | O sistema deverá permitir que bibliotecários cadastrem, editem e removam obras e exemplares. | Essencial |
| RF05 | Pesquisar acervo | O sistema deverá permitir a busca de obras por título, autor, assunto ou ISBN, exibindo a respectiva disponibilidade. | Essencial |
| RF06 | Realizar empréstimo | O sistema deverá registrar o empréstimo de um exemplar a um leitor, informando a data prevista de devolução. | Essencial |
| RF07 | Registrar devolução | O sistema deverá registrar a devolução de exemplares e atualizar a respectiva disponibilidade. | Essencial |
| RF08 | Renovar empréstimo | O sistema deverá permitir a renovação de empréstimos ativos, observadas as regras de negócio. | Importante |
| RF09 | Reservar obra | O sistema deverá permitir que o leitor reserve obras cujos exemplares estejam integralmente emprestados. | Importante |
| RF10 | Controlar atrasos | O sistema deverá identificar os empréstimos em atraso e aplicar a penalidade prevista. | Importante |
| RF11 | Notificar leitor | O sistema deverá notificar o leitor, por e-mail, acerca de vencimentos próximos e da disponibilidade de obras reservadas. | Desejável |
| RF12 | Consultar histórico | O sistema deverá permitir que o leitor consulte seus empréstimos, reservas e pendências. | Importante |
| RF13 | Gerenciar usuários | O sistema deverá permitir que o administrador crie, edite e desative contas de funcionários e de leitores. | Importante |
| RF14 | Gerar relatórios | O sistema deverá gerar relatórios, tais como obras mais emprestadas, atrasos e movimentação mensal. | Desejável |
