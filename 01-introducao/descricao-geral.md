# 1.2. Descrição dos Usuários

O Sistema de Gerenciamento de Biblioteca possui diferentes tipos de usuários, cada um com responsabilidades e permissões específicas.

## Leitor
É o usuário que utiliza o sistema para consultar o catálogo de livros e realizar solicitações de empréstimo.

## Bibliotecário
É responsável pelo gerenciamento do acervo, cadastro e atualização de livros, além do controle dos empréstimos e devoluções.

## Administrador
É responsável pelo gerenciamento geral do sistema, incluindo o controle dos usuários e das permissões de acesso.
