# 2.2. Requisitos Não Funcionais

Os requisitos não funcionais descrevem as características de qualidade e as condições de funcionamento do sistema.

| Código | Requisito |
|---|---|
| RNF01 | O sistema deve possuir uma interface simples e intuitiva. |
| RNF02 | O sistema deve proteger os dados dos usuários. |
| RNF03 | O acesso às funcionalidades deve respeitar as permissões de cada usuário. |
| RNF04 | O sistema deve apresentar informações de maneira organizada e clara. |
| RNF05 | O sistema deve manter a integridade dos dados cadastrados. |
| RNF06 | O sistema deve possuir mecanismos de autenticação para controlar o acesso. |
