
# 2.1. Requisitos Funcionais

Os requisitos funcionais descrevem as funcionalidades que o Sistema de Gerenciamento de Biblioteca deverá oferecer aos seus usuários.

## Lista de Requisitos Funcionais

| Código | Requisito |
|---|---|
| RF01 | O sistema deve permitir o cadastro de livros. |
| RF02 | O sistema deve permitir a consulta de livros disponíveis no acervo. |
| RF03 | O sistema deve permitir o cadastro de leitores. |
| RF04 | O sistema deve permitir que usuários realizem login. |
| RF05 | O sistema deve permitir a realização de empréstimos de livros. |
| RF06 | O sistema deve permitir o registro de devoluções. |
| RF07 | O sistema deve permitir a atualização dos dados dos livros. |
| RF08 | O sistema deve permitir o gerenciamento dos usuários. |
| RF09 | O sistema deve permitir que o usuário encerre sua sessão (logout). |
