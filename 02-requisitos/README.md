## Template de novo documento de requisitos

```markdown
# [Título e seção]

## Objetivo
[O que este documento especifica e quem o utilizará.]

## Requisitos / conteúdo
[Use tabela com identificador, descrição verificável, prioridade e relações aplicáveis.]

## Critérios de validação
[Como cliente, desenvolvimento e testes confirmarão o conteúdo.]

## Histórico de alterações
| Versão | Responsável | Data | Alteração |
|---|---|---|---|
| 1.0 | [Nome] | [DD/MM/AAAA] | [Resumo] |
```
