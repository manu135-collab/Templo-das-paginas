# 2.3. Regras de Negócio

As regras de negócio definem as condições que devem ser respeitadas durante o funcionamento do Sistema de Gerenciamento de Biblioteca.

| Código | Regra |
|---|---|
| RN01 | Somente usuários cadastrados e autenticados podem realizar empréstimos. |
| RN02 | Um livro somente poderá ser emprestado quando estiver disponível. |
| RN03 | Cada leitor poderá manter no máximo 3 empréstimos simultâneos. |
| RN04 | A devolução deverá atualizar a disponibilidade do livro no sistema. |
| RN05 | O sistema deverá registrar os empréstimos realizados pelos leitores. |
| RN06 | Cada usuário deverá acessar apenas as funcionalidades permitidas ao seu perfil. |
