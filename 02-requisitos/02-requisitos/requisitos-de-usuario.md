# Requisitos de Usuário (RU)

Os requisitos de usuário expressam as necessidades na perspectiva da biblioteca e dos perfis que utilizarão o sistema.

| ID | Descrição | Origem |
|---|---|---|
| RU01 | O usuário necessita acessar o sistema de forma segura. | RF01, RF03 |
| RU02 | O leitor necessita realizar seu cadastro na biblioteca por meio do sistema. | RF02 |
| RU03 | O leitor necessita localizar obras e verificar sua disponibilidade. | RF05 |
| RU04 | O bibliotecário necessita registrar empréstimos, devoluções e renovações com agilidade. | RF06, RF07, RF08 |
| RU05 | O leitor necessita reservar obras indisponíveis e ser informado quando estiverem disponíveis. | RF09, RF11 |
| RU06 | O bibliotecário necessita manter o acervo atualizado. | RF04 |
| RU07 | O leitor necessita acompanhar seus empréstimos, reservas e pendências. | RF12 |
| RU08 | O bibliotecário necessita que os atrasos sejam identificados e penalizados automaticamente. | RF10 |
| RU09 | O administrador necessita gerenciar as contas de funcionários e leitores. | RF13 |
| RU10 | O administrador necessita obter relatórios gerenciais sobre o uso da biblioteca. | RF14 |
