## 📖 Sobre o Projeto

Este repositório apresenta a documentação do Sistema de Gerenciamento de Biblioteca, desenvolvido como projeto acadêmico de modelagem de software. O sistema tem como objetivo facilitar a consulta de livros e o gerenciamento de empréstimos para alunos e funcionários.
