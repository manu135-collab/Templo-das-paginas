# 📚 Templo das Páginas
### Sistema de Gerenciamento de Biblioteca Pública

Documentação do projeto acadêmico de Engenharia de Software da Universidade Federal do Amazonas (UFAM), Instituto de Ciências Exatas e Tecnologia (ICET), em Itacoatiara/AM — 2026.

## Sobre o projeto

O Templo das Páginas apoia a gestão de leitores, acervo, empréstimos, devoluções, renovações, reservas, atrasos, notificações e relatórios da biblioteca pública. Consulte os documentos organizados abaixo; os arquivos nas pastas são as fontes detalhadas por assunto.

## Manutenção dos documentos

Ao modificar um requisito, atualize suas histórias, níveis RU/RS/RSW, matriz de rastreabilidade e casos de uso/diagramas relacionados. Registre mudanças relevantes no histórico de versões do documento consolidado. Templates estão incluídos nos arquivos de cada seção para orientar novas entradas.
