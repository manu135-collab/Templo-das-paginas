# 1. Introdução

## 1.1. Descrição Geral do Software

O Sistema de Gerenciamento de Biblioteca tem como objetivo facilitar a organização e o gerenciamento das atividades de uma biblioteca, permitindo o controle de livros, usuários e empréstimos.

## 1.2. Descrição dos Usuários

- **Leitor:** consulta livros e realiza solicitações de empréstimo.
- **Bibliotecário:** gerencia livros, usuários e empréstimos.
- **Administrador:** administra o sistema e suas funcionalidades.
